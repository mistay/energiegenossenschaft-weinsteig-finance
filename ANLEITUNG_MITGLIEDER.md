## 1. Kontostand prüfen (Journal)

Ihr **Kontojurnal** zeigt Ihnen den aktuellen Kontostand - wie viel Sie der Genossenschaft schulden oder wie viel Guthaben Sie haben.

### So sehen Sie Ihr Journal:

1. Loggen Sie sich in **Nextcloud** ein
2. Klicken Sie auf **📊 Journal**
3. Sie sehen jetzt Ihr persönliches Konto mit:
   - **Vorschreibungen** (Rechnungen, was Sie bezahlen müssen)
   - **Zahlungen** (Beträge, die Sie bereits bezahlt haben)
   - **Saldo** (aktuelle Kontostand)

### So interpretieren Sie den Saldo:

#### 🟢 **Guthaben** (z.B. "+150€")
```
Sie haben zu viel bezahlt!
Die Genossenschaft schuldet Ihnen Geld.
→ Sie erhalten eine Rückerstattung oder Gutschrift
```

#### 🟡 **Ausgeglichen** (0€)
```
Ihr Konto ist in Ordnung.
Vorschreibungen = Zahlungen
→ Alles passt zusammen
```

#### 🔴 **Rückstand** (z.B. "-200€")
```
Sie schulden der Genossenschaft Geld!
→ Bitte überweisen Sie den offenen Betrag
```

## 2. Vorschreibungen anschauen

Eine **Vorschreibung** ist Ihre monatliche Rechnung. Sie zeigt, was Sie bezahlen müssen, um den Betrieb der Energiegenossenschaft zu unterstützen.

### Im Journal anschauen:

1. **📊 Journal** öffnen
2. Unter **"Vorschreibungen"** sehen Sie alle Ihre Rechnungen
3. Jede Zeile zeigt:
   - **Datum**: Wann die Rechnung erstellt wurde
   - **Monat**: Für welchen Monat (z.B. "Januar 2025")
   - **Betrag**: Wie viel Sie bezahlen müssen (Standard: 60€)
   - **Status**: Ist die Rechnung bezahlt? (🔴 Offen, 🟡 Teilweise, 🟢 Bezahlt)

### Vorschreibung runterladen:

1. Im Journal auf die Vorschreibungs-Zeile klicken
2. Klick auf **"📥 PDF runterladen"**
3. PDF wird heruntergeladen
4. Speichern oder ausdrucken für Ihre Unterlagen/Buchhaltung

## 3. SEPA-Mandat einrichten

Ein **SEPA-Mandat** ist die Erlaubnis an die Energiegenossenschaft, Geld von Ihrem Bankkonto abzubuchen. Das ist praktisch und spart Ihnen manuelle Überweisungen.

### Schritt 1: Bankkonto (IBAN) hinterlegen

1. Loggen Sie sich in Nextcloud ein
2. Klicken Sie auf **💳 SEPA Lastschrift**
3. Im Bereich **"Kontoinfos"** füllen Sie aus:
   - **IBAN**: Ihre Kontonummer (z.B. DE89370400440532013000)
   - **Kontoinhaber**: Ihr Name (wie er auf der Bank hinterlegt ist)
4. Klicken Sie **"Speichern"**

✓ Das System überprüft Ihre IBAN automatisch!

---

### Schritt 2: Mandatsvorlage herunterladen

1. Im **💳 SEPA Lastschrift** Bereich klicken Sie auf:
   - **"📄 Mandat-Vorlage generieren"**
2. Eine PDF wird heruntergeladen
3. Diese PDF enthält:
   - Alle Infos der Energiegenossenschaft
   - Ihre IBAN (die Sie oben eingegeben haben)
   - Den Text des SEPA-Mandats
   - Ein Unterschriftsfeld

---

### Schritt 3: Unterschreiben (2 Optionen)

#### 🔐 **Option A: Digital per ID Austria** (Empfohlen!)

Das geht schnell und digital:

1. Öffnen Sie das heruntergeladene PDF in der **Nextcloud Web-App**
2. Klicken Sie auf **"🔐 Digital unterschreiben mit ID Austria"**
3. Sie werden zu ID Austria weitergeleitet
4. Melden Sie sich mit Ihren Daten an
5. Bestätigen Sie die Signatur
6. Das PDF wird automatisch signiert und hochgeladen ✓

**Fertig!** Das Mandat ist digital unterschrieben.

#### ✏️ **Option B: Per Hand unterschreiben**

Falls Sie ID Austria nicht nutzen können:

1. Drucken Sie die heruntergeladene PDF
2. Unterschreiben Sie mit einem Kugelschreiber im **Unterschriftsfeld**
3. Scannen oder fotografieren Sie das unterschriebene Papier
4. Speichern Sie es als PDF oder JPG

---

### Schritt 4: Unterschriebenes Mandat hochladen

1. Gehen Sie zu **💳 SEPA Lastschrift**
2. Unter **"Unterschriebenes Mandat hochladen"** klicken Sie:
   - **"📤 Datei wählen"**
3. Wählen Sie das unterschriebene PDF/JPG
4. Klicken Sie **"Hochladen"**

Das System speichert Ihr Mandat und zeigt den Status:

- **🟡 Ausstehend** = Die Kassier:innen müssen es noch überprüfen
- **🟢 Genehmigt** = Alles ok! Lastschriften können jetzt eingezogen werden

---

### Schritt 5: Warten auf Freigabe

Die **Kassier:innen der Genossenschaft** prüfen Ihr Mandat manuell:
- ✓ Unterschrift vorhanden?
- ✓ IBAN korrekt?
- ✓ Name korrekt?

Sobald alles ok ist, geben sie das Mandat **frei** (Status: 🟢 Genehmigt).

**Dann können wir Ihre offenen Beträge einziehen!**

## Häufige Fragen

### F: Wie oft werden Beträge eingezogen?
**A:** Die Kassier:innen erstellen monatlich einen Datenträger mit allen Lastschriften. Dieser wird zur Bank gebracht. Danach dauert es ein paar Tage, bis das Geld eingezogen wird.

### F: Kann ich mein Mandat widerrufen?
**A:** Ja! Unter **💳 SEPA Lastschrift** → **"🚫 Mandat widerrufen"**. Dann funktionieren Lastschriften nicht mehr. Sie können aber jederzeit ein neues Mandat hochladen.

### F: Was wenn ich meine IBAN ändern möchte?
**A:** Neue IBAN eingeben, neue Mandatsvorlage herunterladen, unterschreiben, hochladen. Das alte Mandat bleibt für die Unterlagen erhalten.

### F: Wo sehe ich meine Zahlungen?
**A:** Im **📊 Journal** unter **"Zahlungen"** sehen Sie alle Beträge, die eingezogen wurden:
- Datum
- Betrag
- Von welcher Bank

### F: Was bedeutet "Teilweise bezahlt"?
**A:** Sie haben einen Teil der Rechnung bezahlt, aber noch nicht alles.
Beispiel: Rechnung 60€, Sie haben 40€ bezahlt → Noch 20€ offen.

### F: Wer ist die Kassier:in?
**A:** Die Kassier:innen sind gewählte Mitglieder der Genossenschaft, die sich um Finanzen kümmern. Bei Fragen können Sie diese direkt kontaktieren.

### F: Warum muss ich ein SEPA-Mandat unterschreiben?
**A:** Das ist eine rechtliche Anforderung der Bank. Sie geben damit die Erlaubnis, Geld vom Konto abzubuchen. Das ist sicher und normal.

## 💡 Tipps & Tricks

1. **Regelmäßig checken**: Schauen Sie 1x pro Monat ins Journal, um Ihren Kontostand zu prüfen
2. **Vorschreibungen aufbewahren**: Die PDFs sind gut für Ihre Buchhaltung - speichern Sie sie!
3. **Probleme melden**: Falls etwas nicht stimmt, kontaktieren Sie die Kassier:innen oder Admin
4. **Fragen stellen**: Sie können jederzeit im Journal etwas nicht verstehen - fragen ist ok!
